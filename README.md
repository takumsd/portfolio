# Portfolio Website

このリポジトリは [GitHub Pages](https://pages.github.com/) でホストされているポートフォリオサイトのソースコードです。

**公開URL:** https://takumsd.github.io/portfolio/

## 🛠 更新手順 (How to Update)

**このサイトの更新は、基本的に AI エージェント (Antigravity) を通じて行います。**
自分でファイルを編集したり、コマンドを叩いたりする必要はありません。

チャットで以下のように依頼してください：

*   「ポートフォリオの自己紹介文を更新したい」
*   「新しい実績画像を `Works_10.webp` として追加したい」
*   「レイアウトを少し調整したい」

Antigravity がローカルでファイルを修正し、GitHub へのアップロード (Push) まで行います。

---

## 📂 フォルダ構成 (Reference)

AIに指示する際の参考にしてください。

*   **`index.html`**: サイトの骨組み（HTML構造）
*   **`src/data/content.js`**: 文章データ（自己紹介、経歴、プロジェクト詳細など）
*   **`images/`**: 画像フォルダ（`Works_XX.webp` や `portrait.jpg` など）
*   **`files/`**: 配布用ファイル（PDFなど）

## ⚠️ トラブルシューティング

**Q. 更新したのにサイトが変わらない**
A. GitHub Pages の反映には **1〜2分** かかることがあります。少し待ってからブラウザを再読み込みしてください。
それでも変わらない場合は、**スーパーリロード** (Mac: `Cmd` + `Shift` + `R`) を試してください。

**Q. 画像が表示されない**
A. ファイル名の **大文字・小文字** が合っているか確認してください（`works_01.jpg` と `Works_01.jpg` は別のファイルとして扱われます）。

**Q. Google検索に出てこない**
A. プライバシー保護のため、意図的に検索避け設定 (`noindex`) をしています。URLを知っている人だけがアクセスできます。
